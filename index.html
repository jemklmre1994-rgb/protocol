FI CREDENTIALS PROTOCOL

Follow the sequence below. Only QA-qualified interviewers may proceed to credential generation.

1 CREATE PROJECT FOLDER

Create a folder named after the given PROJECT in SharePoint.

OPEN PROJECT FOLDER ↗

↓

2 COMPLETE CREDENTIALS TEMPLATE

Copy/paste CREDENTIALS TEMPLATE SCRIPTING ONLY into the PROJECT folder.

Open the copied folder and fill in all required details and data.

↓

3 QA CHECK

Is the interviewer qualified by QA?

NO

HOLD

Do NOT generate passwords for unqualified interviewers.

Stop until qualification is confirmed.

YES
↓

4 SET USERNAME AND GROUPNAME

USERNAME = PROJECT identifier + first letter of interviewer’s name + surname

Example: zenith_jdequiroz

GROUPNAME = PROJECT NAME + _ + TAGGING

Example: zenith_min

Use the highlighted legend in the template to select TAGGING.

↓

5 GENERATE PASSWORD(S)

OPEN STRONG PASSWORD GENERATOR ↗

Advanced settings

Length: 12

Begins With: A–Z

No Duplicate Characters

✓ Alpha Upper (A–Z)

✓ Number (0–9)

✓ Symbol: @

Generate one password for each QA-qualified interviewer.
